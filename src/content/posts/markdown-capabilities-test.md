## Code Blocks

### JavaScript Example

```javascript
function greet(name) {
  console.log(`Hello, ${name}!`);
}

greet('World');
```

### Python Example

```python
def greet(name):
    print(f"Hello, {name}!")

greet("World")
```

### Astro Example

```astro
---
const name = "World";
---

<h1>Hello, {name}!</h1>
```
